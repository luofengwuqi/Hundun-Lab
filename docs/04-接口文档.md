## 1. 通用约定

### 1.1 基地址

| 环境 | 基地址 | 说明 |
| --- | --- | --- |
| 本地开发 | `http://localhost:5577/api` | Vite 把 `/api` 代理到 `:5757` |
| 生产同源 | `https://<域名>/api` | Nginx 反代到 `:5757` |
| 生产跨域 | `https://<后端域名>/api` | 需在 `CORS_ALLOWED_ORIGINS` 登记前端域名 |

前端 `src/api/http.js` 的 `baseURL` 固定为 `/api`，**换环境不改代码**（README「部署前提」）。

### 1.2 统一响应

```jsonc
// 成功
{ "code": 200, "errorCode": null, "message": "success", "data": { /* ... */ } }

// 失败
{ "code": 404, "errorCode": "DOWNLOAD_ASSET_NOT_FOUND", "message": "中文兜底文案", "data": null }
```

- `code`：业务状态码（HTTP 状态码大类在此体现）。
- `errorCode`：**稳定不变**的枚举码，前端据此查 i18n 文案（`src/i18n/{zh,en}.js` 的 `errors.*`）。
- `message`：中文兜底，**只用于日志与"前端没有对应文案"的场景**，用户看到的永远是本地化后的文案。
- 前端判定：`http.js` 拦截器里 `code === 200 || code === 0` 视为成功并直接返回 `data`，其余抛 `ApiError`。

### 1.3 鉴权模型

```
Authorization: Bearer <jwt>
```

| 环节 | 规则 |
| --- | --- |
| `TokenResolveFilter` | 只解析令牌写入上下文，**不做任何放行判断** |
| `AccessControlInterceptor` | 唯一放行决策点：**默认拒绝**，标 `@PublicApi` 才公开；`/admin/**` 前缀 + `@RequireRole` 再校验角色 |
| 匿名请求 | `BaseContext.getCurrentId()` 返回 `null`（**不会伪造 id=0 的假用户**） |
| 令牌吊销 | 登出即删 Redis 令牌；账号被禁用时每次请求校验状态并即时拦截 |
| 存储键 | `localStorage['hundunlab.token']`（前端），有效期默认 24h |

### 1.4 限流模型

`@RateLimit(count = N, time = 秒, key = "...", resetOnSuccess = true|false)`，维度为 **IP + 账号双维度**；
超限返回 `429 RATE_LIMITED`。`resetOnSuccess = true` 表示成功后清零（登录类接口用，避免误伤后长时间锁定）。

### 1.5 分页

反馈与（未来的）插件列表用 `page` / `size`；`size` 上限 200（`@Max(200)`）。下载记录用 `limit`（默认 20，上限 100）。

### 1.6 文件上传

`multipart/form-data`，字段名 `file`。服务端校验白名单 + 图片魔数（`FileUploadValidator`）。
上传配额 `UPLOAD_MAX_FILE_SIZE`（默认 20MB）。**安装包不走这里**（走管理端专用接口流式转存 OSS）。

### 1.7 隐私

`User` 实体的 `passwordHash` 与 `inviteCode` 带 `@JsonIgnore`，**任何 JSON 响应都不会带出**；
`toString()` 也已排除。新增 VO 时不得直接返回实体以外的敏感字段。

## 3. 已实现接口

### 3.1 站点

#### `GET /software` —— 已发布软件列表

- 鉴权：公开。返回 `SoftwareSummaryVO[]`。

| 出参字段 | 类型 | 说明 |
| --- | --- | --- |
| `slug` | string | URL 标识 |
| `nameZh` / `nameEn` | string | 双语名称 |
| `taglineZh` / `taglineEn` | string | 一句话简介 |
| `coverUrl` / `themeColor` | string | 封面与主色 |
| `platforms` | string[] | 如 `["win32","linux"]` |
| `latestVersion` | string | 最新已发布版本号，无则空 |
| `latestPublishedAt` | datetime | |
| `totalDownloads` | number | 累计下载量 |

> 中英文案一次返回，切语言不重新请求。

#### `GET /software/{slug}` —— 软件详情

- 鉴权：公开。返回 `SoftwareDetailVO`（一次聚合，避免详情页串行发多个请求）。

  "techStack": ["Electron 28", "Vue 3"],
  "repoUrl": "...", "license": "MIT",
  "coverUrl": "...", "themeColor": "#C3272B",
  "features":    [{ "icon": "...", "titleZh": "...", "titleEn": "...", "descZh": "...", "descEn": "..." }],
  "screenshots": [{ "imageUrl": "...", "captionZh": "...", "captionEn": "..." }],
  "platforms":   [{ "platform": "win32", "noteZh": "...", "noteEn": "..." }],
  "releases": [{
      "id": 1, "version": "26.2.1024", "channel": "stable",

- 错误码：`SOFTWARE_NOT_FOUND`（404，软件不存在或尚未发布）

### 3.2 下载

#### `POST /download/ticket` —— 换取下载票据

- 鉴权：**登录**（刻意不加 `@PublicApi`；匿名点下载应被挡下并由前端弹登录框）
- 限流：30 次 / 60 秒（key `download:ticket`）
- 入参：`{ "assetId": 1 }`（`DownloadRequestDTO`，`@Valid`）
- 出参 `DownloadTicketVO`：

| 字段 | 说明 |
| --- | --- |
| `url` | OSS 预签名地址，**5 分钟有效** |
| `fileName` / `fileSize` / `sha256` | 供前端展示与校验 |
| `expiresIn` | 有效秒数（300） |

- 服务端校验链：软件已发布 → 版本已发布 → 资产属于该版本；随后**同一事务**内 `download_count++` 并写 `download_record`。
- 错误码：`DOWNLOAD_ASSET_NOT_FOUND`(404)、`DOWNLOAD_STORAGE_UNAVAILABLE`(503，OSS 未配置)、`DOWNLOAD_FILE_MISSING`(404)、`AUTH_NOT_LOGGED_IN`(401)、`RATE_LIMITED`(429)

#### `GET /download/mine?limit=20` —— 我的下载记录

- 鉴权：登录；返回 `DownloadRecord[]`（`limit` 默认 20，上限 100）

### 3.3 登录与注册

| 路径 | 入参 | 出参 |
| --- | --- | --- |
| `POST /user/login/username-password` | `{ username, password }` | `LoginRequestVO` |
| `POST /user/login/phone-password` | `{ phone, password }` | 同上 |
| `POST /user/login/email-password` | `{ email, password }` | 同上 |
| `POST /user/login/email-code` | `{ email, code }` | 同上 |
| `POST /user/login/email-code/send` | `{ email }` | `Void`（**3 次/60 秒**） |
| `POST /user/login/logout` | 无（取当前令牌） | `Void` |
| `POST /user/register` | `RegisterDTO` | `RegisterVO` |
| `POST /user/register/admin` | `RegisterDTO` + 邀请码 | `RegisterVO` |

```jsonc
// LoginRequestVO
{ "token": "eyJhbGciOi...", "user": { "id": 1, "username": "wuqi", "nickname": "芜柒", "status": 1, ... } }
```

- 错误码：`USER_PASSWORD_WRONG`(400)、`USER_EMAIL_CODE_WRONG`(400)、`USER_EMAIL_CODE_EXPIRED`(400)、
  `USER_EMAIL_SEND_FAILED`(500)、`USER_ALREADY_EXISTS`(409)、`AUTH_ACCOUNT_DISABLED`(403)、`RATE_LIMITED`(429)
- 注册冲突**统一**返回 `USER_ALREADY_EXISTS`（防账号枚举，不透露是用户名还是邮箱被占）。

## 6. 前端调用约定

| 约定 | 内容 |
| --- | --- |
| 实例 | `src/api/http.js`（axios，超时 12s；下载票据 30s） |
| 错误 | 非 2xx 抛 `ApiError{ errorCode, message, status }`，**不弹全局 toast、不强跳登录**（匿名站点） |
| 文案 | 组件不显示 `message`，用 `i18n` 的 `errors.<code>`；查不到回落 `common.error` |
| 令牌 | 请求头自动带 `Authorization: Bearer <hundunlab.token>` |
| 下载门 | 未登录点下载 → 记住 `assetId` → 弹登录框 → 登录成功后自动续传 |
