## 编号使用约定（写给自己和接手人）

1. 新决策接着当前最大号往后排（写这份时是 D070），不复用、不重排。
2. 被替代的条目**不删除、不改写**，在原文下加一行 `> 已被 Dxxx 替代（日期）。原文保留供追溯。`
   **D093 修订（2026-11-17）**：仅"完全失效且无残留效力"者可整条移入 §R 墓碑区；部分失效一律保留原文。
3. 一条 D 只装一个决定。发现一条里混了两个不相关结论，拆开并互相标注。
4. 状态与确认方式是两栏：状态答"进行到哪一步"，确认方式答"怎么来的"（独立选择／采纳建议／转述甲方／书面签认）。
5. `Q` 答完变 `D`，同时把 Q 标为"已答"，并写明生成了哪条 D。
6. 拿最大编号用命令，不靠记忆：

```bash
grep -ohE "D[0-9]{3}" docs/prd/*.md | sort -u | tail -1
```

> 该写法按字典序排序，编号过千后会失效（四位数与三位数的顺序会颠倒）；届时改用 `sort -t D -k2 -n`，并把编号补齐到四位。
