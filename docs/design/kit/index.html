Hundun 物料库

把原型拆成可直接取用的独立物料：一层纯 CSS（hundun-kit.css）+ 一套 Vue 组件（src/components/hundun）。 两端共用同一套类名与设计令牌，改一处两边同时生效。

变量 作用 默认
--hd-cart-accent顶部斜纹主色，按软件 theme_color 覆盖var(--hd-red)
--hd-cart-cut卡带切角大小9px
--hd-cart-edge描边厚度2px
--hd-cart-paper纸面颜色#f7e7ca
--hd-cart-line描边颜色#5a352a
--hd-cart-slab侧面（厚度）颜色#b0402e
立体感配方：① ::before 深棕八边形描边 → ② ::after 内缩 2px 的纸面 + 顶部高光 → ③ filter: drop-shadow(9px 10px 0) 实心红色塑料侧面 → ④ 再叠一层带模糊的落地柔影。 切角不能用 border（会被 clip-path 一起裁掉），所以描边是「外层深色八边形 + 内层浅色八边形」两层裁出来的。
