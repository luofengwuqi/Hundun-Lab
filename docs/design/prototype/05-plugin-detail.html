# PixelRuler

轻量级的屏幕取色与像素测量插件，常驻菜单栏。

  • 全局快捷键唤起取色器
  • 测量任意两点间像素距离
  • 测量结果一键复制为 CSS 变量

权限声明

读写剪贴板
复制颜色值
不访问网络
全部数据本地处理
