## 结构

- `assets/proto.css` — 唯一一份样式表，顶部是设计令牌（色板 / 字体 / 尺度 / 阴影），下面按组件分节：页头、按钮、卡带卡、插件卡、扩展分区（`.ext-*`）、徽标、表格、表单、登录页。
- 页面之间靠普通 `<a>` 互链，导航可点：首页 ↔ 软件列表 ↔ 详情 ↔（页内扩展分区）↔ 插件详情 ↔ 提交 ↔ 个人信息。登录页刻意不带页头，被设计为独立入口。

## 字体

标题用 **Fusion Pixel 12px（缝合像素字体）**，SIL OFL 1.1，可商用。字体文件在 `assets/fonts/fusion-pixel-12px-sc.woff2`（589 KB，含简体中文），许可原文同目录 `LICENSE-OFL.txt`。

- 像素字体的设计网格是 12px，**只在 12 的整数倍字号下最锐利**：现用 96 / 64 / 48 / 40 / 24px。
- 字重固定 400，不要加 `font-weight: bold`——浏览器合成粗体会让像素边缘糊掉。
- 正文、卡片名、按钮用系统无衬线（微软雅黑），小标签与数字用等宽。

## 一屏显示（头部 + 主体 = 一屏，页脚贴底）

页面按「应用外壳」实现：`body` 是 `flex column`，页头固定 90px，`main` 取 `flex: 1` 吃掉剩余高度，页脚被顶到窗口最底边。**窗口多高，页面就多高**——不会出现滚动条，也不会在页脚下面留一条空白。

主体内部按页面类型决定「谁来吸收多余高度」，都是让内容长高而不是留白：

| 页面 | 吸收多余高度的块 | 表现 |
| --- | --- | --- |
| `01` | `.hero` + `.shelf` | 扉页 hero 占上半屏，货架卡片撑满下半屏 |
| `02` | `.section--fill` 卡片栅格 | 两行卡片等高，下载行各自贴卡片底 |
| `03` | `.band--fill` 分栏带（只到扩展分区之前） | 面板长到一屏底部；扩展分区在三屏之外，见下 |
| `03b` | `.section--fill` 版本表 | 表格行随高度拉开 |
| `05` | `.body--fill` 左栏 | README 长高，右侧两块面板一上一下 |
| `06` | `.submit--fill` 右栏 | 表单面板长高，「提交审核」贴面板底 |
| `07` | `.profile--fill` 右栏 | 「我的扩展」长高，四行均分 |

**窗口比设计稿矮时等比缩放**：设计基准是 1024 高，低于 1013 起每 32px 一档，整页 `zoom` 逐档缩小（0.96 → 0.64）。等比缩放而不是压间距，所以任何高度下版式比例都和设计图一致，只是整体小一号。`zoom` 会让 `100vh` 跟着变小，因此每档同时写了 `min-height: calc(100vh / 缩放比)` 补回来。缩放只作用于带 `.site-header` 的页面——登录页是 100vh 满屏设计，不缩放。

实测（1536×1024，Firefox）：**7 页一屏**（01/02/03b/05/06/07/08），页脚都在可见范围内。03 是唯一长页——它把原 04 的扩展分区收了进来（D074），总高约 1750px，扩展分区要滚一次才看全。这是合并的必然结果，不是版式退化。

## 与设计图的差异

1. **像素标题**已用真字体还原，字形与设计图接近；设计图里的字是 AI 直接画的，个别笔画不完全一致属正常。
2. **掌机插画**改用内联 SVG 重绘（`01`、`03` 两页），线条比图里更规整。
3. **06 提交页**表单字段较密，左栏两块面板贴顶、剩余高度留在栏底（与设计图一致），右栏表单撑到页脚。
4. **主题切换**已实现（D082）：内联脚本先设 `data-theme` 防闪白，深色令牌在 `proto.css` 末尾统一覆盖，组件不写颜色字面量。深色的用色规则见 D087——**绿只做描边，字一律白**：文字走 `--ink`（深色下为白），强调文字走 `--accent-text`（浅色=主色，深色=白），绿色 `--red`/`--teal` 仅用于边框、分隔线、方块标记与选中态描边；实心绿底承载文字的组件在文件末尾统一降级为「绿描边 + 白字 + ≤12% 绿透明底」。
5. 尺寸按 `docs/design/mockups/` 的实测坐标校准：版心 1312px、页头 90px、hero 标题 96px、卡片 236px 起、面板圆角 16px。
6. 页脚比设计图多一档「标语 + 三个红方块」（来自首页参考图），内页沿用同一份。
